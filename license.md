## ❓ What Is KMS Activation

| **Term** | **Description** |
|-----------|-----------------|
| **KMS** | Key Management Service |
| **GVLK** | Generic Volume License Key |

| **180 days** | KMS renewal cycle |
| **Client** | The PC being activated |

**Why use it?**
- ✅ Simple activation flow

## 🔧 Setup Walkthrough

### Step 1 — Confirm Edition
Verify you have a volume-eligible license.

### Step 2 — Open PowerShell
Press `Win + X` → Windows PowerShell (Admin).

### Step 3 — Set KMS Host
Point the client at the KMS server.

### Step 4 — Install GVLK
Apply the Generic Volume License Key.

### Step 5 — Activate
Trigger activation with `slmgr /ato`.

### Step 6 — Verify
Run `slmgr /xpr` to confirm.
